# Update the AI Log

1. Read `docs/AI_LOG.md`; create it with a `# AI Log` heading if it does not exist.
2. Identify the current milestone and add a section if needed.
3. Ask the student to confirm the AI tool/model, the task, the main prompt, what was generated, and what they kept, changed, or rejected.
4. Ask whether the AI was wrong or produced poor code. Record only examples the student confirms.
5. Do not invent prompts, tools, models, mistakes, or student decisions.
6. Show the proposed entry and ask for confirmation before treating it as final.
